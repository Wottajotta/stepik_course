# Проект: VA - Chatbot in style of a Brand

## Описание

Репозиторий содержит демонстрацию цепочки на базе LangChain и OpenAI, чат-бота в стиле бренда, а также скрипт автоматической оценки стиля ответов с сохранением отчёта в JSON.

## Требования

* Python **3.9+**
* `pip`
* Доступ к OpenAI API

## Установка

1. Клонируйте репозиторий и перейдите в каталог проекта.
2. Установите зависимости:

```bash
pip install -r requirements.txt
```

3. Создайте файл окружения:

```bash
cp .env.example .env
```

4. Откройте `.env` и укажите:

* `OPENAI_API_KEY` — обязательный параметр
* `OPENAI_API_BASE` — обязательный параметр
* `OPENAI_MODEL` — обязательный параметр
* `PROMPT_VERSION` — опционально
## Запуск

### Демо цепочки

Запуск демонстрационного скрипта цепочки:

```bash
python src/brand_chain.py
```

### Чат-бот в стиле бренда

Запуск чат-бота:

```bash
python app_lc.py
```

### Автоматическая оценка стиля

Запуск скрипта автооценки ответов:

```bash
python src/style_eval.py
```

После выполнения будет сформирован файл отчёта:

```text
reports/style_eval.json
```
